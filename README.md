# Kasboek — downloads

Kasboek is een privacy-first app voor je persoonlijke financiën. Al je gegevens blijven versleuteld op je eigen computer; er gaat niets naar een server.

Deze repository bevat alleen de installers en updatebestanden. Je hoeft Kasboek maar één keer te downloaden: daarna zoekt de app zelf naar nieuwe versies en werkt zichzelf bij.

## Eerste keer openen

- **macOS:** klik met rechts op Kasboek → *Open* → *Open*.
- **Windows:** kies bij "Windows heeft uw pc beschermd" *Meer info* → *Toch uitvoeren*.
- **Linux:** maak de AppImage uitvoerbaar (`chmod +x kasboek-linux.AppImage`) of installeer de `.deb`.
